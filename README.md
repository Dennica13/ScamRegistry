# 🛡️ ScamRegistry (WoW 3.3.5a)

**ScamRegistry** — это легкий и удобный аддон для World of Warcraft 3.3.5a (Wrath of the Lich King), созданный для быстрого обнаружения недобросовестных игроков (кидал) в группе, рейде или личном поиске.

Все данные о нарушениях хранятся прямо в базе аддона, а актуальный список нарушителей обновляется вместе с загрузкой новых версий.

## 📌 Основные возможности

* **Сканирование рейдов и групп:** Автоматическая проверка всех участников вашей группы или рейда на наличие жалоб в базе в один клик.
* **Предварительный просмотр:** Возможность изучить список найденных нарушителей перед отправкой сообщений в чат.
* **Отправка предупреждений:** Удобные кнопки для анонса найденных кидал в `/p` или `/raid` чат.
* **Проверка конкретного игрока:** Быстрый просмотр истории нарушений выделенного в цель персонажа (`Target`).

## 🎮 Кнопки интерфейса

Аддон предоставляет компактную плашку управления, которую можно перетаскивать мышкой в любое удобное место экрана:

* **Скан** — запускает сканирование текущего состава группы или рейда. Открывает окно предварительного просмотра с найденными нарушителями и кнопками отправки информации в чат.
* **Цель** — открывает окно с подробным списком всех зафиксированных жалоб на выбранного в цель игрока.
* **Жалоба** — вызывает окно с готовой ссылкой на Discord-сервер проекта для подачи новой жалобы.

## 💬 Слэш-команды

Вы также можете управлять аддоном через чат с помощью команд `/sr` или `/scam`:

| Команда | Описание |
| :--- | :--- |
| `/sr` | Показать справку по командам |
| `/sr ui` | Показать / восстановить панель управления |
| `/sr scan` | Просканировать текущую группу или рейд |
| `/sr target` | Проверить текущую цель (`Target`) |
| `/sr <Ник>` | Проверить конкретного игрока по имени (например: `/sr Нявая`) |

## 📥 Установка и обновление

1. Скачайте архив с последней версией аддона или клонируйте репозиторий.
2. Распакуйте папку `ScamRegistry` в директорию игры:  
   `World of Warcraft/Interface/AddOns/`
3. Убедитесь, что путь выглядит следующим образом:  
   `World of Warcraft/Interface/AddOns/ScamRegistry`

> **💡 Совет по обновлению:** Чтобы база кидал всегда оставалась актуальной, регулярно обновляйте файл `Database.lua`, скачивая свежую версию из этого репозитория.

## 📢 Как подать жалобу или оспорить внесение

Мы придерживаемся строгой политики модерации. Записи в базу вносятся **только при наличии доказательств**, чтобы исключить клевету.

Если вы столкнулись с кидаловом на лут/голду или хотите подать апелляцию:

1. Перейдите на наш Discord-сервер: **[https://discord.gg/ZeRn5tuKTc](https://discord.gg/ZeRn5tuKTc)** *(или нажмите кнопку **«Жалоба»** в самом аддоне)*.
2. Откройте канал `#подать-жалобу`.
3. Оформите заявку по шаблону:
   * **Ник нарушителя:** (точный ник)
   * **Игровой мир / Фракция:** (например, *WoW Circle x1, Орда*)
   * **Суть нарушения:** (краткое описание)
   * **Доказательства:** (полноразмерные скриншоты или видеозапись)
